# Acceptance Criteria — Validate Intelligence

- [ ] **Verificação de Conteúdo Mínimo**: Specs com menos de 50 caracteres em Outcome são marcadas como FAIL.
- [ ] **Consistência de Terminologia**: Se o glossary define um termo, a spec deve usá-lo.
- [ ] **Detecção de Tom**: Specs marcadas como "formal" não devem conter gírias ou coloquialismos.
- [ ] **Drift Temporal**: Alertar se a spec tem mais de 30 dias sem atualização.
