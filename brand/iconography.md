# Iconography — Letra

## Princípio

A iconografia deve parecer parte do mesmo sistema modular do símbolo da marca.

## Características

- traço limpo
- cantos suaves
- geometria simples
- leitura rápida em tamanhos pequenos

## Estilo

- outline predominante
- preenchimento reservado para alertas, badges e estados especiais
- espessura consistente entre 1.5px e 2px em base 24

## Referências de forma

- círculos para agentes, presença e nós
- losangos para entrega, release e marcos
- linhas conectadas para workflow e dependência
- retângulos suaves para contexto, cards e painéis

## Regras

- usar Amber para foco ou estado ativo, não para todos os ícones
- ícones semânticos usam a cor do estado
- nunca misturar ícones ultra detalhados com UI minimalista

## Ícones prioritários da marca

- workflow
- agents
- execution
- review
- approval
- blocked
- delivered
