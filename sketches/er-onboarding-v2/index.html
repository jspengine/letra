Relacionamentos
Workspace 1 ──── N CONTÉM N ──── 1 Project
Project 1 ──── N ESCANEIA N ──── 1 Repository
Project N ──── N APLICA N ──── 1 Gate (via ProjectGate)
Gate 1 ──── N PERMITE N ──── 1 AgentCapability
AgentRole 1 ──── N POSSUI N ──── 1 AgentCapability
Capability 1 ──── N É USADA EM N ──── 1 AgentCapability
Capability define ação EM scope (comment/approve/close)
Workspace / AgentCapability Project Repository FlowTemplate Gate AgentRole Capability
